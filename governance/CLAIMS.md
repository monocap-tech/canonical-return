# Claim custody and interpretation

| Classification | Meaning |
|---|---|
| CANONICAL | Result stated in a referenced primary paper; not a new Canonical Return theorem. |
| DERIVED / ANALYTIC | Independent mathematical derivation recorded in the archive, not externally reviewed. |
| AUDIT-PASS | Executable computation or interval assertion passed; only its explicitly checked statements. |
| CONDITIONAL | Requires a published or explicitly conjectural missing hypothesis. |
| OPEN | Missing analytic estimate, completed domain, metric/intertwiner, or spectral theorem. |
| STOP / NO TRANSFER | Existing evidence does not permit promotion into an RH proof jurisdiction. |

## Not proven

Global Weil positivity, the Riemann hypothesis, equality of completed Suzuki/Connes operator domains, a Deninger arithmetic Hodge cohomology with the required spectrum, Connes's general semilocal complement estimates, or the original RH STRICT/BAL terminal obligations.

## Selected claims currently tracked

- Suzuki scalar formula: *canonical identity* on a common smooth test core; completed-domain extension open.
- Morishita: *canonical dynamical orbit map*, with elementary orbitwise Haar unitary; no global pairing transfer.
- Connes–Consani: *canonical semilocal trace and Sonin results* within their stated domains, plus source-level analyses; complex mixed trace extension is an analytical deduction subject to review.
- Deninger: *conditional* weight-one Hodge argument; the additional cohomology and positivity assumptions are not constructed.
- T1B: *AUDIT-PASS* exact selected Hermitian Gram numerator and mass denominator; not a full operator decomposition.
- T1C: *AUDIT-PASS* rational analytical enclosures for one selected 2D pole-null source; not a global lower bound.

Preserve original full signed Weil form **poles minus prime plus Gamma**; track first/second argument conjugate conventions; do not infer an infinite-dimensional spectral gap from a compressed pencil. Mathematics here should not be presented as peer-reviewed or Lean-certified merely because it has been archived on GitHub.
